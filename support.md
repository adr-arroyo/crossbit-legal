# Soporte de CrossBit

Para recibir ayuda con la aplicación, solicitar la eliminación de tu cuenta o ejercer tus
derechos de privacidad, escribe a **crossbitapp@gmail.com**. Incluye el tipo de dispositivo,
la versión de la aplicación y una descripción del problema. No envíes contraseñas, claves de
API ni información de salud innecesaria.
